# Image Slider Project

## About the Project
The Image Slider is a simple web development project created using HTML, CSS, and JavaScript. It displays images one by one and allows users to move between slides.

## Features
- Next and Previous buttons
- Automatic image sliding
- Image captions
- Navigation dots
- Responsive and simple design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Files
- `index.html` – Structure of the webpage
- `style.css` – Styling and design
- `script.js` – Slider functionality

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Click the Next and Previous buttons to change images.
